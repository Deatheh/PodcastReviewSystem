# Система отзывов о подкастах

Консольное приложение для управления подкастами и сбора отзывов пользователей о них.

## Возможности
- Добавление подкастов с проверкой уникальности и длины названия.
- Добавление отзывов к существующим подкастам по ID.
- Просмотр списка подкастов и отзывов о них.
- Сохранение и загрузка данных в формате JSON.
- Обработка некорректного пользовательского ввода.

## Структура проекта
- `main.py` – точка запуска и меню приложения.
- `podcasts.py` – функции для работы с подкастами.
- `reviews.py` – функции для работы с отзывами.
- `storage.py` – загрузка и сохранение данных (JSON).
- `utils.py` – вспомогательные функции безопасного ввода.
- `data/` – каталог для JSON-файлов с данными.
- `tests/` – автоматизированные тесты pytest.

## Требования
- Python 3.x
- pytest
- flake8
