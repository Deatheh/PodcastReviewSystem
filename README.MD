# Система отзывов о подкастах

## Название проекта
Система отзывов о подкастах

## Назначение
Приложение предназначено для управления подкастами и сбора отзывов пользователей о них. Система позволяет добавлять подкасты, оставлять комментарии и оценки, а также отслеживать рейтинг подкастов.

## Целевая аудитория
- Слушатели подкастов, желающие делиться своим мнением
- Авторы подкастов, интересующиеся обратной связью от аудитории
- Платформы распространения подкастов

## Предметная область
Система управления контентом подкастов с функционалом рецензирования и рейтингования.

## Основные сущности
- **Podcast (Подкаст)** - основная сущность, содержащая информацию о подкасте
- **Review (Отзыв)** - сущность для хранения комментариев и оценок пользователей
- **User (Пользователь)** - пользователи системы, оставляющие отзывы

## Основные функции
- **addPodcast(title)** - добавление нового подкаста в систему с проверкой уникальности названия и минимальной длины
- **addComment(podcastId, text)** - добавление комментария к существующему подкасту
- **isExsistPodcatById(id)** - проверка существования подкаста по идентификатору
- **isExsistCommentById(id)** - проверка существования комментария по идентификатору
